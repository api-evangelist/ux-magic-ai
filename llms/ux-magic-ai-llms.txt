# UXMagic

> UXMagic is an AI UI/UX design tool that turns text prompts, screenshots, hand-drawn sketches, website URLs, and existing Figma files into pixel-perfect, Figma-ready UI designs and production-ready code in seconds. Built by UXMagic Inc. (US), it is trusted by 50,000+ designers, developers, product managers, and founders.

UXMagic helps teams go from idea to interface fast: generate complete multi-screen UI flows, low-fidelity wireframes, and full style guides with AI, then export to Figma, Framer, Webflow, React, and HTML/Tailwind.

## Generate UI from anything
- [AI UI Generator](https://uxmagic.ai/ai-ui-design-generator): Turn text prompts into pixel perfect figma ready UI.
- [Image to UI](https://uxmagic.ai/image-to-ui): Upload a screenshot and get production-ready code.
- [Sketch to UI](https://uxmagic.ai/image-wireframe-to-ui): Convert paper sketches into polished digital interfaces.
- [Clone any Website](https://uxmagic.ai/clone-any-website): Recreate any website design by providing a URL.
- [Import from Figma](https://uxmagic.ai/import-from-figma): Bring your existing Figma projects into UXMagic.

## Design & edit
- [Flow Mode](https://uxmagic.ai/flow-mode-ai-ui-generator): Generate your entire multi-screen UI flow from one prompt.
- [Style Guide Generator](https://uxmagic.ai/ai-style-guide-generator): Generate brand colors, typography, and components in seconds.

## Structure & ship
- [AI Wireframe Generator](https://uxmagic.ai/ai-wireframe-generator): Generate Low fidelity wireframes to plan your structure
- [Image Screenshot to Wireframe](https://uxmagic.ai/image-to-wireframe): Convert any screenshot into a clean, editable wireframe

## Features (complete list)
- UI Design: Generate polished, high-fidelity UI screens from a plain-text prompt.
- Wireframe Mode: Generate low-fidelity wireframes and user flows to plan structure first.
- Sectional Editing: Edit a single section of a screen without regenerating the whole thing.
- Flow Mode: Create an entire multi-screen user flow from a single prompt.
- Screenshot to UI: Turn any screenshot into editable, production-ready UI.
- Sketch to UI: Convert a rough or hand-drawn sketch into a polished digital interface.
- Clone a Site (from URL): Recreate any website's layout from its URL for inspiration and exploration.
- Text Editing & Upload Images: Edit content inline and add your own images to designs.
- Style Guide: Generate and apply consistent brand colors, typography, and components.
- Import Figma Components / Design System: Bring your existing Figma components and design system into UXMagic.
- Export Code: Export production-ready HTML, React, and Tailwind code for developer handoff.
- Figma Export: Export high-fidelity, auto-layout, dev-ready designs straight to Figma.
- Export to Framer & Webflow: Export and publish generated designs directly to Framer and Webflow.
- Per-project collaborator invites: Invite specific people by email to collaborate on a project.
- Anyone-with-link share: Share a link that adds anyone who opens it to the project.

## Exports & integrations
- Figma: export high-fidelity, dev-ready, auto-layout designs to Figma — or import an existing Figma file and edit it with AI.
- Framer & Webflow: export and publish generated designs directly to Framer and Webflow.
- Code: export production-ready HTML, React, and Tailwind CSS from any generated design.
- Figma plugin: [UXMagic AI UI Generator (Website to Figma, Screenshot to UI)](https://www.figma.com/community/plugin/1374402598280022366/uxmagic-ai-ui-generator-website-to-figma-screenshot-to-ui) — [UXMagic on Figma](https://www.figma.com/@uxmagic).
- Component libraries: [Figma component library](https://uxmagic.ai/figma-component-library), [React component library](https://uxmagic.ai/react-component-library).
- Developer tools: MCP server ([uxmagic-mcp@1.2.0 on npm](https://www.npmjs.com/package/uxmagic-mcp?activeTab=readme)) for Cursor, Windsurf, VS Code, Claude and other IDEs — setup in the docs.

- UX Magic Pro — $17.5/month: 1,200 monthly credits · up to 200 screens (Unlimited projects, 250 Figma exports).
- Enterprise — Custom pricing: Custom credits based on team plan (Everything in Pro, plus team & security features).
- Enterprise adds: Unlimited AI-generated screens, Unlimited team seats, Custom credit allocation, SSO / SAML authentication, Team admin dashboard, Shared design system & component library, and more.
- Prices in USD. Paid plans are billed monthly or annually; a free tier is always available with no credit card. See uxmagic.ai/pricing for current plans.
